System Architecture

Data flows left to right through five layers. Each layer has one job and talks to the next through a clean interface.

LAYER 1

Data Ingestion

📈 Alpaca
S&P 500 daily OHLCV
5-year history

📰 Alpaca News
Headlines per ticker
Rolling 30-day window

📊 FMP API
Earnings actuals
vs analyst estimates

📋 Static list
S&P 500 constituents
(updated quarterly)
LAYER 2

Feature Engineering

📐 Price momentum
1m / 3m / 12m returns
(skip last week)

🔄 Mean reversion
5-day return reversal

🧠 NLP sentiment
FinBERT on headlines
→ daily score per ticker

💰 Earnings surprise
(actual − est) / |est|
Post-earnings drift

📏 Cross-sectional rank
All features z-scored
within S&P 500 daily
LAYER 3

ML Model

🌲 LightGBM
Gradient boosting
Fast, interpretable

🎯 Target
20-day forward return
(cross-sectional rank)

🔁 Walk-forward
2yr rolling train window
Retrain monthly

📊 Output
Predicted return score
for each of 500 stocks
LAYER 4

Portfolio Construction

🏆 Rank & select
Top 25 by predicted score
Long-only positions

⚖️ Volatility parity
Size each position by
inverse 20-day vol

🏭 Sector cap
Max 30% in any
one sector

📅 Weekly rebalance
Replace stocks that
drop out of top 25
LAYER 5

Risk Engine

🛡️ Position limits
Max 8% per stock
Hard ceiling

🔪 Kill switch
Daily loss > 2%
→ exit all positions

📉 Drawdown cap
Portfolio DD > 15%
→ scale to 50% cash

🌡️ Regime filter
VIX > 30 → halve
all position sizes

📝 Audit log
Every decision written
to decisions.jsonl
▼ all layers feed into
EXECUTION

Alpaca Paper Trading API → orders placed, tracked, and logged. Daily P&L report. SPY benchmark comparison. Signal attribution (which factor contributed how much to today's picks).

Each layer is a separate Python module. They talk through DataFrames — clean, testable, replaceable. The risk engine is the last gate before any order reaches Alpaca.
