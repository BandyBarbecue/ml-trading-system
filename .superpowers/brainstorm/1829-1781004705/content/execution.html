Section 6: Daily Execution Loop + Directory Layout

One script orchestrates everything. Runs each morning before market open. Every decision is logged.

The daily pipeline — 8:30 AM ET

1. Fetch data — ~2 min

Top-up yesterday's price bars (500 stocks via Alpaca). Fetch overnight news headlines. Update VIX. Check for new earnings reports (FMP).

2. Claude NLP extraction — ~3 min, ~$0.30

Send new headlines to Claude Haiku in batches of 20. Cache results — already-processed headlines are skipped. Output: news_scores + supply_chain_scores per ticker.

3. Compute features + IC update — ~30 sec

Price momentum, mean reversion, vol for all 500. Merge news scores and earnings surprise. Recompute 60-day rolling IC for each feature. Cross-sectional z-score everything.

4. ML inference (+ monthly retrain) — 30 sec daily / 5 min monthly

Daily: run LightGBM on today's features → predicted_score for 500 stocks. First trading day of month: retrain on rolling 2-year window with updated IC weights.

5. Portfolio construction (Mondays only) — ~10 sec

Select top 25. Run HRP on their 60-day covariance. Apply sector cap. Diff against current holdings. Generate trade list with turnover cap enforced.

6. Risk engine veto + execute — ~5 sec

VIX check, drawdown check, position limits. If all clear: submit orders to Alpaca paper trading API. Log every decision (approved or vetoed) to decisions.jsonl.

7. Daily report — printed to terminal + saved

P&L vs SPY benchmark. Current 25 positions + weights. Top signals: which stocks moved up/down the ranking and why. Factor attribution: what % of today's picks were driven by momentum vs news vs earnings.
